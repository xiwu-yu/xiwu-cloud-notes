## 视觉和体验

- 首页两个入口共用材质；主入口强调蓝灰轮廓与文字权重，次入口使用粉色文字及轻边缘。背景云朵、宋体标题和原有文案保留。
- 称呼卡与个人介绍使用轻内容材质。背后的蓝粉云雾向边缘淡出，面板自身不堆彩色渐变。
- 文章卡片只有一个主要轮廓，封面不模糊，摘要保持纸面，日期不再单独套盒。移动单列、桌面多列及单结果布局沿用。
- 归档工具区为搜索行与操作行；日期展开后增加高度，窄屏/长语言必要时允许换行，筛选值与恢复功能不变。
- 资源为桌面两列、手机单列圆角卡片。FAQ 共用一个圆角玻璃外框，内部用细线分隔，不重复加滤镜。
- 联系图片的透明度、饱和度和纸色遮罩保持正式站原样；仅邮箱短文字使用 media 材质。章节标记和标题无底托；页脚“再翻一篇”仍在“回到云端”下方、右对齐且无玻璃。
- 长文保持手机 17px / 1.85 / 左右 20px、桌面最长 720px 的稳定纸面，正文不随通透度改变。阅读主题切换、关闭、焦点、Esc、历史及静态无 JS 正文保留。

这是一套背景透色、模糊和边缘反光的 Web 材质，不是完整 Apple 光学折射。没有引入 SVG 位移滤镜、WebGL、动画框架或新依赖。

## 一个入口，一份设置

原重叠圆图标改为“玻璃外观”，不新增重复入口。桌面面板靠近按钮，手机使用带安全区的底部面板；内容较高时内部滚动，关闭入口保持可达。使用原生 modal dialog，并在阅读时挂到文章 dialog 内，再进入浏览器原生顶层；没有用 z-index 绕过顶层/inert 关系。Esc 先关闭设置，回到原入口，再次 Esc 才关闭文章。展开期间导航不闲置隐藏，关闭及移出导航交互后重新计时。

开关命名为「玻璃云间」，四语言同步。默认开启、通透程度 55。快捷档位为柔和 20、均衡 55、通透 90；滑块支持完整 0–100。关闭保留上次数值，恢复默认回到开启/55。

存储键为 `xiwu-glass-appearance`，值为 `{version:1, enabled:boolean, clarity:number}`。旧 `xiwu-reduce-transparency=true` 表示关闭；读取旧偏好后正常迁移，保存时兼容写回旧键。数值仅接受有限 number，超范围夹到 0–100；损坏 JSON、非法结构、未知版本使用安全默认/旧偏好。存储不可用时仍能在当前文档调整。

滑块 input 只通过单个 rAF 合并更新根 CSS 变量，change 才保存；卡片、正文、播放器节点都不重建。首页、阅读弹窗和独立文章复用同一模块，其他标签页通过 storage 事件同步。静态文章的设置模板在构建时使用实际语言输出，不依赖 profile.js。

## 三类材质与回退

共享映射先使用 `t=(clarity/100)^.85`，再计算底色遮盖量，**不是把数值赋给容器 opacity**：

| 类别 | 0 → 100 底色遮盖范围 | 使用位置 |
|---|---|---|
| control | .76 → .34 | 导航、操作工具条、按钮、选中指示器 |
| content | .90 → .62 | 简介、身份卡、文章外壳、资源、FAQ、设置及音乐大面板 |
| media | .62 → .24 | 联系图片上的邮箱 |

按最新反馈提高三类材质通透度；默认 55 时底色遮盖量约为 control .507、content .732、media .391，保留文字不透明。设置说明使用更清晰的正文色，避免暗色透色后对比不足。背景模糊由 18px 轻降到 12px；边缘反光独立管理，中央没有大面积斜白带。移除所有组件固定 `--glass-fill`，组件仅选择对应的类型变量；父子材质不重复采样 backdrop。前景文字、图标、图片和焦点轮廓不降低透明度。

系统强制颜色、高对比度、减少透明度优先，其次是浏览器支持能力和用户开关。面板显示实际生效原因，但不覆盖保存的 enabled/clarity。关闭、不支持背景模糊或 color-mix、脚本失败时使用稳定实色；无 JS 内容不被隐藏。减少动态会取消非必要位移/缩放、高光和 FAQ 动画，保留原生 details 行为。

动效：按压 140ms、悬停 180ms、设置/FAQ 240ms、分类及视图底托 280ms。只有底托做 FLIP，文字不拉伸；没有持续 rAF 动画循环。原有云朵暂停逻辑与音乐同页节点稳定机制保留。

## 验收与复现

新增 `tests/e2e/appearance.spec.mjs` 覆盖五种宽度、四语言双主题、关闭与 0/55/100、连续 input、快捷档位与重置、旧偏好、损坏/非法/禁用存储、刷新、独立文章、跨标签同步、系统覆盖与恢复、无滤镜、阅读嵌套 modal、Esc/焦点、导航计时、200% 等效布局/文字放大、减少动态、音乐节点与 FAQ 反向开合。原有功能断言保留；旧“一键开关”和“只有一个 dialog”的测试按新入口契约更新。

构建与读取生成文件的测试依次运行，避免产物相互覆盖。最终结果：22 项单元测试、构建、106 项 Chromium E2E、106 项 WebKit E2E，以及本地 13 页 / 16 资源静态校验均通过。涵盖全部旧功能及新增设置回归；正常宿主页面未发现控制台错误、资源失败或整页横向溢出。

实际补查发现并修正了：设置打开时浏览器返回关闭两层 modal 后，子 modal 的 inert 使父阅读器恢复焦点过早；现于捕获阶段先关闭子 modal，再恢复到文章链接，并验证前进重新打开。滑块焦点轮廓曾靠近说明首行，增加 8px 间距后重新采样。

第一次完整 WebKit 测试的 7 个失败属于键盘策略与测试接口差异：旧站快照和新版本都以 Option+Tab 遍历按钮/范围控件；另外 WebKit 自动化不提供 clipboard-write 权限。已用独立快照检查确认原行为，按原生策略修改键盘测试；Chromium 继续使用真实剪贴板权限，WebKit 用明确的宿主剪贴板 fixture 验证分享 URL/错误回退，不冒充系统剪贴板实测。没有删除键盘或分享断言。可参考 [Apple 的 Safari 键盘说明](https://support.apple.com/guide/safari/keyboard-shortcuts-and-gestures-cpsh003/mac)。

对比度脚本在 320/390/1440px、四语言、双主题、通透度 0/55/100 下采样了 936 个可见文字区域：最低 **4.620:1**，无低于 4.5:1 的样本。隐藏目标文字但保持布局，采集实际合成截图，只统计未被 sticky 导航等遮挡的可见文字范围。结果与逐项采样在 `work/glass-unified/contrast/`，不能推论为任意背景/所有滚动位置的保证。

发布 PR 首轮云端验证还发现一条帧调度依赖：分类翻译重绘后，旧断言立即读取暂时离开 DOM 的指示器。控制时钟独立复现为下一帧前 disconnected、32ms 后同一节点 reconnect；现等待重绘完成后验证对象身份，并保留唯一节点、连续移动和减少动态断言。没有用重试整个测试或放宽对象身份要求绕过失败。
