## 实际变化

1. **手机长文优先**：手机弹窗为接近全屏的阅读面板，正文 17px / 1.85、左右 20px。桌面正文为 18px、最长 720px，保留各语言系统字体。正文与卡片采用稳定实色背景。阅读工具条在自身滚动容器内固定，44px 控件支持关闭、语言、回到云端及减少透明效果；Esc、历史导航、分享和焦点恢复继续使用既有逻辑。
2. **清楚的归档层级**：「云间来信」为主标题，原句「一些思考，一点情绪」为副标题，英文/繁中/日文对应拆分。搜索始终可见；写作/上传时间、月份和升降序放入原生 details，默认收起。分类与卡片/时间轴仍可直接使用，闭合时显示非默认日期条件数；折叠不清空筛选，空结果可恢复。
3. **材质与节奏**：统一间距、圆角、阴影及短动效变量。玻璃仅用于全宽导航、归档工具条、音乐按钮和阅读工具条；没有嵌套玻璃，移除了原有 dialog 全页背景模糊和音乐面板模糊。保留原有云朵、插画、蓝粉暖白、文案及导航显隐逻辑。
4. **视觉偏好**：新增独立 `appearance.js`，在样式前恢复 `xiwu-reduce-transparency`，主站/静态页共用。系统减少透明度、高对比度、强制颜色优先，手动按钮通过 aria-pressed 与说明反映状态；系统强制时不允许手动反向覆盖。存储不可用时本页仍能切换。减少动态会同时禁用 CSS 高光/按压与 JS 指针更新。
5. **静态阅读不退化**：`scripts/static.mjs` 输出对应语言控件及带内容哈希的增强脚本。真实正文、lang、canonical、OG、hreflang、返回链接、项目子路径与 sitemap 均保留。脚本失败或禁用时正文可见，手动增强按钮隐藏，不以加载动画延迟阅读。
6. **音乐保持当前方式**：只给现有音乐按钮增加材质 class；现有官方 iframe、移动 HTTPS 入口、按需加载、auto=0、节点稳定与失败提示继续保留。本轮不上传 MP3，也未替换音源。

主要源文件：`dist/index.html`、`dist/style.css`、`dist/script.js`、新增 `dist/appearance.js`、`scripts/static.mjs`、`scripts/music.mjs`、`content/ui.json`。新增 `tests/e2e/design.spec.mjs`，同步配置、原有筛选/焦点测试与单元 fixture 的构建输入。`scripts/design-evidence.mjs` 可重现截图和资源实测；Actions 仅增加该证据命令，权限、验证门槛、PR 不部署及 main 发布流程均未扩大或改写。旧音乐验收报告保持原样，记录的是上一阶段。
