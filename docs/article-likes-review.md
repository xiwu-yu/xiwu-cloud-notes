# 文章点赞验收

基于 GitHub main / 正式站 `591bc49feb600f6d2a55357f6d523e88ad389fc0` 的隔离副本开发；原工作区的文章、插画、音乐等未提交改动未修改。文章正文、生产域名、Pages workflow 和音乐配置没有变动。

## 功能与边界

- 新增 `dist/likes.js`、`scripts/likes.mjs`、四语言文案及阅读弹窗/静态模板入口；构建注入配置与内容哈希，不手改生成的 `profile.js`。
- `workers/likes/` 提供官方 Workers / D1 后端、数据库迁移与配置。唯一关系和计数触发器在同一事务完成，前端不提交 count。
- 匿名凭证保存在浏览器，数据库存 HMAC；按文章 ID 跨语言、跨阅读入口共享。支持取消、刷新、同源标签页同步、故障提示、基础限流和安全降级。
- 作者选择自行配置 Cloudflare，因此当前 `apiUrl:null`，生产集成保持关闭；未创建云端数据库、部署 Worker 或生成假累计。完整接通步骤见 [部署说明](article-likes.md)。

## 实际验证

- 修改前：24 项单元、构建、117 项 Chromium E2E 全通过。
- 修改后：30 项单元、构建、124 项 Chromium E2E 全通过；新增 7 项 WebKit 点赞测试全通过。
- 新测试覆盖真实 SQLite 约束/触发器/事务、不同访客共享计数、幂等添加/取消、并发、来源/身份/文章/请求体校验、限流和过期项清理、服务故障；前端覆盖刷新、跨语言、跨标签页、待处理请求、存储被禁、超时、重试、无 JS、播放器节点稳定。
- 官方 Wrangler 4.153.0 / workerd 本地 D1 正式迁移成功；5 次并发重复点赞返回累计 1，独立身份读取 1 且未喜欢，取消和重复取消均返回 0。全部是本地数据库，没有写入生产。

日志、浏览器报告、截图和本地 D1 数据在忽略的 `work/article-likes/` / `.wrangler/`，不提交海量截图或数据库。新增测试沿用既有 CI 单元/E2E 门槛和失败 Artifacts；不增加 workflow 权限。

Wrangler 仅是开发依赖，不增加前端框架。新增前端脚本约 5.3KB 原始文本；精确 gzip 与样式增量保存在本地资源测量中，不声称真实 CDN 传输或 Lighthouse 分数。
