# 获准发布的玻璃界面与交互改进

作者于 2026-10-26 确认本地效果并授权提交、推送和部署。改动沿用静态 HTML/CSS/JavaScript、Markdown 构建、四语言和现有发布流程，没有新增框架或依赖。

## 最终实现

- `dist/style.css`：分离玻璃填色、边缘反光、阴影和交互高光；首页按钮、卡片外框、搜索/阅读工具条和音乐面板共用材质。中央不覆盖大面积斜白带，卡片摘要使用稳定纸面，前景封面不模糊。保留不透明回退、减少透明、减少动态和强制颜色支持。这不是完整的光学折射实现，没有 SVG 位移滤镜或 WebGL。
- `dist/appearance.js`：分类与卡片/时间轴共用一个移动底托实现，每组一个 aria-hidden 节点，340ms FLIP transform；文字保持稳定。语言、窗口和字体变化后重测，保留 aria-pressed、键盘和无 JS 回退，减少动态时直接定位。
- `dist/index.html`、`dist/script.js`：阅读弹窗的主题按钮与主站共用偏好；保留关闭、焦点恢复、历史、搜索、日期排序与筛选。more to be / continued... 取消斜体并左对齐；“再翻一篇”在页脚“回到云端”下方、右对齐且无玻璃。
- `scripts/music.mjs`、`dist/music-drag.js`、`content/ui.json`：音乐重复说明收进原生使用帮助。桌面可拖动标题、方向键移动（Shift 加大步长）、Home 复位，窗口变化后约束边界；手机/触屏保持固定定位。同页操作不更换 iframe、src 或 contentWindow。仍使用官方可见控件和 auto=0，不伪造跨域播放控制。

## 图片以正式站原样为准

作者最后明确要求采用之前 cloud.xiwu.space 的图片深浅并停止调色。已从正式站 CSS 和 build-info（`f3dd8cff7fa429ddad2416cbf3dbdb6b86bab145`）读取并原样恢复：图片层透明度 .62、saturate(.9)、主题纸色遮罩 .45，桌面和手机使用原有实现。删除了审阅中临时增加的固定底色和混合比例。标签、标题和邮箱直接叠图，不恢复其底托。

`tests/fixtures/contact-production.css` 保存正式站图片规则和移动断点。320/390/1440px、双主题分别比较本地截图与参考样式渲染，检查图片保持一致。没有修改原图、文章正文、站点基址、域名、DNS、Pages 设置或工作流权限。浏览量统计按作者决定未实现。

## 验证与证据

发布前按顺序执行锁定依赖安装、单元测试、构建和完整 E2E，再运行 WebKit 设计/玻璃回归、本地静态校验，以及与 CI 相同的三项证据采集。本地结果：22 项单元测试、92 项 Chromium E2E、25 项 WebKit 回归、13 页 / 16 资源校验及三项证据采集均通过。云端结果以此次 PR Checks 与 Actions 为准；发布后使用 main 的完整合并 SHA 核对 `build-info.json`、静态元数据和带哈希资源。

本轮先合入最新 main：保留了作者更新的简介、FAQ 与四语言文案；新增音乐界面翻译，并按作者要求将栏目标题改为“阅读资源”和“一些问题”、同步四语言，文章和其他作者原话保持不变。合并冲突仅涉及生成的 profile.js 引用哈希，由构建重新生成。

截图和日志在忽略的 `work/`，CI 继续通过已有 Actions Artifacts 保存证据、报告和失败 trace，不向仓库加入大量图片或日志。开发时的 v2–v7 对照均为历史记录，不能当成当前线上状态。`scripts/glass-v3-evidence.mjs` 可重现本地截图；音乐截图使用明确标注的宿主 fixture，不是实际播放证明。

已进行有限的真实桌面 Safari 视觉检查，手机为尺寸和 WebKit 引擎模拟。真实音频输出、地区/版权限制和 iPhone Safari 播放仍未验收；整页导航会离开当前播放器。曾记录官方 iframe 在 HTTP localhost 上尝试跨域访问父页的错误，没有屏蔽或放宽浏览器安全策略。
